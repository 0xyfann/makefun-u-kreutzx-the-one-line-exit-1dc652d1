One funny one-line resignation letter, for the make.fun competition "The One-Line Exit".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> I hereby resign — after five years as the office's only IT guy, I've finally fixed my biggest bug: this job.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
